COVID-19 Analysis Dashboard

This Power BI dashboard provides a comprehensive analysis of global COVID-19 trends, enabling users to monitor confirmed cases, deaths, recoveries, testing, vaccination progress, and country-wise performance through interactive visualizations.

Project Overview

  • Developed using Microsoft Power BI
  • Data cleaned and transformed using Power Query
  • Created data model using Star Schema
  • Built DAX measures for KPIs and trend analysis
  • Interactive filters, slicers and drill-through navigation

Dashboard Features

  • Global COVID-19 Summary
  • Top 10 Countries by Cases
  • Top 10 Countries by Deaths
  • Recovery Rate Analysis
  • Death Rate Analysis
  • Vaccination Progress
  • Daily Trend Analysis
  • Interactive Map Visualization

Technologies Used

  • Power BI Desktop
  • Power Query
  • DAX
  • SQL
  • Star Schema Data Modeling
