COVID-19 Analysis Dashboard

Interactive Power BI dashboard providing executive insights into global COVID-19 trends through KPI monitoring, country-wise analysis, and daily trend visualization.

Project Overview

Designed and developed an interactive Power BI dashboard to analyze global COVID-19 data. The dashboard enables users to monitor pandemic trends, compare country-level performance, and track key health metrics through intuitive visualizations and executive-level reporting.

Dashboard Highlights

  • Executive summary of Confirmed, Recovered, Active, and Death cases.
  • Country-wise analysis using Top 5 and Top 10 visualizations.
  • Interactive world map displaying active COVID-19 cases.
  • Daily and monthly trend analysis for confirmed cases and deaths.
  • Recovery Rate and Death Rate KPI monitoring.
  • Weekly comparison of confirmed cases with percentage change.
  • Interactive slicers, drill-downs, and page navigation for enhanced user experience.

Technologies Used

Power BI DAX Power Query SQL Star Schema Data Modeling Data Visualization
